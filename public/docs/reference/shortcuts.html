Documentation/Reference

Keyboard shortcuts

Every key, by screen.

Review inspector

Key Action
← → Previous / next image, saving edits first
A Verify and go to the next image
R Rework (write the reason first)
U Back to unverified
I Isolate
B Show or hide boxes
Delete Backspace Delete the selected box
Ctrl+S Save box edits
Ctrl+Enter Post the comment
Esc Deselect the box, then close

Full-screen viewer (browse)

Key Action
← → Previous / next image
C Add a comment (sets the image back to unverified)
Esc Close

Editor

Key Action
V Select tool
B Box tool
P Polygon (mask) tool; Enter closes the polygon
K Keypoint tool
0 Fit the image
Wheel Zoom; drag empty space to pan
Delete Backspace Delete the picked vertex or keypoint, otherwise the object
Ctrl+Z / Ctrl+Shift+Z Undo / redo (Ctrl+Y also redoes)
Ctrl+S Save as a new version
← → Previous / next image (saves first)
Esc Cancel the drawing, then deselect, then close

Findings reviewer

Key Action
← → Previous / next image
↑ ↓ Move between findings on this image
Z Close-up or whole image
C Label is right
F Fix — opens the editor
A Ambiguous
L Later
X Exclude image
U Undo the decision
Esc Close

Sample viewer (Samples)

Key Action
← → Previous / next image
[ ] Previous / next round
Space Play the rounds
L / G Labels / the model's boxes
M Only the mistakes
K / R Keep / remove
U Undo
F, + − Fit, zoom in, zoom out
Esc Close

Everywhere

Key Action
Esc Close the dialog or the full-screen view
Enter Confirm the dialog
Click and Shift-click Select one, then a range, in review

On this documentation site, / or Ctrl+K opens search.
