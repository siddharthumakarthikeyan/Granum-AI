## Review inspector

| Key | Action |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> | Previous / next image, saving edits first |
| <kbd>A</kbd> | Verify and go to the next image |
| <kbd>R</kbd> | Rework (write the reason first) |
| <kbd>U</kbd> | Back to unverified |
| <kbd>I</kbd> | Isolate |
| <kbd>B</kbd> | Show or hide boxes |
| <kbd>Delete</kbd> <kbd>Backspace</kbd> | Delete the selected box |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save box edits |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Post the comment |
| <kbd>Esc</kbd> | Deselect the box, then close |

## Full-screen viewer (browse)

| Key | Action |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> | Previous / next image |
| <kbd>C</kbd> | Add a comment (sets the image back to unverified) |
| <kbd>Esc</kbd> | Close |

## Editor

| Key | Action |
|---|---|
| <kbd>V</kbd> | Select tool |
| <kbd>B</kbd> | Box tool |
| <kbd>P</kbd> | Polygon (mask) tool; <kbd>Enter</kbd> closes the polygon |
| <kbd>K</kbd> | Keypoint tool |
| <kbd>0</kbd> | Fit the image |
| Wheel | Zoom; drag empty space to pan |
| <kbd>Delete</kbd> <kbd>Backspace</kbd> | Delete the picked vertex or keypoint, otherwise the object |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Undo / redo (<kbd>Ctrl</kbd>+<kbd>Y</kbd> also redoes) |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save as a new version |
| <kbd>←</kbd> <kbd>→</kbd> | Previous / next image (saves first) |
| <kbd>Esc</kbd> | Cancel the drawing, then deselect, then close |

## Findings reviewer

| Key | Action |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> | Previous / next image |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move between findings on this image |
| <kbd>Z</kbd> | Close-up or whole image |
| <kbd>C</kbd> | Label is right |
| <kbd>F</kbd> | Fix — opens the editor |
| <kbd>A</kbd> | Ambiguous |
| <kbd>L</kbd> | Later |
| <kbd>X</kbd> | Exclude image |
| <kbd>U</kbd> | Undo the decision |
| <kbd>Esc</kbd> | Close |

## Sample viewer (Samples)

| Key | Action |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> | Previous / next image |
| <kbd>[</kbd> <kbd>]</kbd> | Previous / next round |
| <kbd>Space</kbd> | Play the rounds |
| <kbd>L</kbd> / <kbd>G</kbd> | Labels / the model's boxes |
| <kbd>M</kbd> | Only the mistakes |
| <kbd>K</kbd> / <kbd>R</kbd> | Keep / remove |
| <kbd>U</kbd> | Undo |
| <kbd>F</kbd>, <kbd>+</kbd> <kbd>−</kbd> | Fit, zoom in, zoom out |
| <kbd>Esc</kbd> | Close |

## Everywhere

| Key | Action |
|---|---|
| <kbd>Esc</kbd> | Close the dialog or the full-screen view |
| <kbd>Enter</kbd> | Confirm the dialog |
| Click and <kbd>Shift</kbd>-click | Select one, then a range, in review |

On this documentation site, <kbd>/</kbd> or <kbd>Ctrl</kbd>+<kbd>K</kbd> opens search.
